## 🚨 The Perimeter Alarm 🚨

**The Mission:** The zombies are getting close! We need an alarm that we can trigger anytime just by calling its name. Create a function called `sound_alarm`. Inside the function, make it print "WARNING: ZOMBIES AT THE GATE!" and "RUN TAKE YOUR BAGS!".

**Check your work:** Run your function once at the bottom to make sure the alarm actually rings!

## 🎒 The Gear Checker 🎒

**The Mission:** You have a list called `backpack` containing "Water", "Map", and "Flashlight". Sometimes we forget what we're carrying! Create a function called `check_gear`. Inside the function, print your entire `backpack` list so you can see your supplies.

**Check your work:** Add a new item ("Snack") to your list, then run your `check_gear` function to see if the snack shows up in your bag!

## 🕺 The Victory Dance 🕺

**The Mission:** You survived the night! To celebrate, you need a function that performs a three-step dance. Create a function called `victory_dance`. Inside the function, print these three lines in order:

1. "Slide to the left!"
2. "Spin around!"
3. "Moonwalk!"

**Check your work:** Run the `victory_dance` function. You should see all three moves appear in the right order!

### 🛡️ Mission 1: The Supply Scanner

The alarm is great, but we need to know *what* we're defending! Let's make a function that can identify any item we find.

* **The Task:** Create a function called `identify_supply`.
* **The Input:** Give it one input variable called `item`.
* **The Logic:** Inside the function, make it print: `"Scanning... Found one: "` followed by whatever the `item` is.
* **Check Your Work:** Run the function twice. Once with `"Medkit"` and once with `"Crossbow"`.

### 🥗 Mission 2: The Ration Report

We need to keep track of our supplies! Let's make a function that announces how long the survivors will be eating.

* **The Task:** Create a function called `calculate_rations`.
* **The Inputs:** Give it two input variables: `survivors` and `days`.
* **The Logic:** Inside the function, make it print a message combining the inputs: `"Feeding [survivors] survivors for [days] days!"`.
* **Check Your Work:** Run the function using the numbers 5 and 7.

### 🚀 Mission 3: The Robot Guard-Dog

You’ve built a robot dog to distract the zombies. You need to be able to tell it which direction to run and how fast to go.

* **The Task:** Create a function called `distract_zombies`.
* **The Inputs:** Use two input variables: `direction` and `speed`.
* **The Logic:** Print a message that combines the inputs: `"Robot Dog is sprinting [direction] at [speed] miles per hour!"`.
* **Check Your Work:** Run the function and tell the dog to go `"North"` at a speed of `25`.
