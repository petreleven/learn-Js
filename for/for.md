### Challenge 1: The Countdown Blast-Off

**The Mission:** Your rocket is preparing for launch! It needs to count backward from 10 to 1 so the team knows when to ignite the thrusters.

**The Goal:**

* Write a `for` loop where the variable `countdown` starts at **10**.
* The loop should run as long as `countdown` is **greater than 0**.
* Use `countdown -= 1` to count backward.
* Inside the loop, print: `"T-minus "+countdown`

**The Result:**

```text
T-minus 10
T-minus 9
T-minus 8
...
T-minus 1

```

### Challenge 2: The Sprinter’s Marathon

**The Mission:** A robot is training for a marathon and wants to track its progress by jumping through checkpoints every 5 kilometers.

**The Goal:**

* Write a `for` loop where the variable `km` starts at **5**.
* The loop should run as long as `km` is **less than or equal to 40**.
* Use `km += 5` to count by fives.
* Inside the loop, print: `"Checkpoint reached:" +km"`

**The Result:**

```text
Checkpoint reached: 5km
Checkpoint reached: 10km
...
Checkpoint reached: 40km

```

### Challenge 3: The Even Number Generator

**The Mission:** A computer needs to list all the even numbers between 0 and 20 to calibrate its internal sensors.

**The Goal:**

* Write a `for` loop where the variable `num` starts at **0**.
* The loop should run as long as `num` is **less than or equal to 20**.
* Use `num += 2` to skip the odd numbers.
* Inside the loop, print: `"Sensor calibrated: "+ num`

**The Result:**

```text
Sensor calibrated: 0
Sensor calibrated: 2
Sensor calibrated: 4
...
Sensor calibrated: 20

```
