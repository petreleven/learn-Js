### 9️⃣ The Secret Agent Counter 🕵️‍♂️

**The Mission:** Count to **10**, but if the number is **7**, shout "TOP SECRET" instead of the number!

> **YOUR CODE:**
> **REPEAT** from number **1 to 10**:
>
> * **IF** the number is **7**:
>    * Say: "TOP SECRET! 🤐"
>
> * **ELSE**:
>    * Say: The number.
