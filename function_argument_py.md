## Challenge 1: The Gamer Level-Up

### The Lore

You just won the big game! Your screen flashes "Double XP Mode!" You need to write a quick code to show your new, higher score.

### The Task

Write a function called `doubleXP` that takes one argument called `points`. Inside the function, multiply the points by 2 and print it to the screen with a victory message.

* **Example Output if you pass in `50`:** `"You leveled up! Your new XP is: 100"`

### Step-by-Step Guide

* **Step 1:** Use `def` to define a function named `doubleXP`.
* **Step 2:** Inside the parentheses `()`, add the argument `points`. Don't forget the colon `:` at the end!
* **Step 3:** Indent your code (press Tab) so Python knows it’s inside the function.
* **Step 4:** Create a new variable that multiplies `points` by `2`.
* **Step 5:** Use `print()` to show your victory message and the result.

## Challenge 2: The Superhero Name Generator

A villain is on the loose! You are a genius scientist coding a machine that creates cool superhero names to save the city.

### The Task

Write a function called `makeHeroName` that takes two arguments: `adjective` and `animal`. Combine them and print a hero name that will save the day.

* **Example Output if you pass in `"Mega"` and `"Hamster"`:** `"Look out! It's Mega Hamster!"`

### Step-by-Step Guide

* **Step 1:** Use `def` to create a function named `makeHeroName`.
* **Step 2:** Inside the parentheses, add two arguments: `adjective` and `animal`, separated by a comma. Add a colon at the end.
* **Step 3:** Indent your code.
* **Step 4:** Use `print()` to combine the text `"Look out! It's "` with the `adjective` and the `animal`.

## Challenge 3: The Pizza Party Planner

Write a function called `pizzaParty` that takes three arguments: `cheesePizzas`, `pepperoniPizzas`, and `veggiePizzas`. Add them together and print the total number of boxes.

* **Example Output if you pass in `3`, `4`, and `2`:** `"Total pizzas ordered: 9"`

### Step-by-Step Guide

* **Step 1:** Use `def` to create a function named `pizzaParty`.
* **Step 2:** Inside the parentheses, add three arguments: `cheesePizzas`, `pepperoniPizzas`, and `veggiePizzas`, separated by commas. End with a colon.
* **Step 3:** Indent your code.
* **Step 4:** Create a variable that adds all three arguments together using the `+` sign.
* **Step 5:** Use `print()` to show the total number of pizzas.

## Challenge 4: The Robot Whisperer

You built a robot buddy! Now you need to program its voice box so it can shout a friendly greeting to anyone it meets.

### The Task

Write a function called `robotGreet` that takes one argument called `userName`. Have the function print a loud greeting using that name in all capital letters.

* **Example Output if you pass in `"Leo"`:** `"BEEP BOOP! HELLO LEO. I AM A ROBOT."`

### Step-by-Step Guide

* **Step 1:** Use `def` to create a function named `robotGreet`.
* **Step 2:** Add one argument named `userName` inside the parentheses. Add a colon.
* **Step 3:** Indent your code.
* **Step 4:** Use the `.upper()` method on the `userName` variable to make it capital letters, then use `print()` to show the robotic greeting.

## Challenge 5: The Pet Age Calculator

### The Lore

Your dog looks very smart today. You want to know how old they would be in "dog years." Let's build a calculator to find out!

### The Task

Write a function called `dogYears` that takes an argument called `humanAge`. Multiply the age by 7 and print the result.

* **Example Output if you pass in `10`:** `"In dog years, your pet is: 70"`

### Step-by-Step Guide

* **Step 1:** Use `def` to create a function named `dogYears`.
* **Step 2:** Inside the parentheses, add one argument named `humanAge`. Add a colon.
* **Step 3:** Indent your code.
* **Step 4:** Multiply `humanAge` by `7` using the `*` symbol and store it in a variable.
* **Step 5:** Use `print()` to show the final calculated age to the screen.
