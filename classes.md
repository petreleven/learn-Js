### 📦 Mission 1: The Pet Trainer

To train your digital pets, you need to create a class that tracks their status with simple console logs—no constructor or arguments needed here!

* **The Mission:** Create a class called `Pet`.
* **The Attributes:** Create a new pet object called `myPet`. Add these attributes one by one using dot notation on separate lines:
* `myPet.name = "Your Pet's Name"`
* `myPet.species = "Your Pet's Species"`
* `myPet.hunger = 0`


* **The Logic:** Add a method (function) inside your class called `feed()` that takes no arguments. Inside the method, use a simple console log to print: `this.name + " is eating and feels happy!"`
* **Check Your Work:** Call `myPet.feed()` and use a console log to check your pet's name and hunger level!
