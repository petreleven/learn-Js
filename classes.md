### 📦 Mission 1: The Pet Trainer

To train your digital pets, you need to create a class that tracks their status.

* **The Mission:** Create a class called `Pet`.
* **The Constructor:** Should take two arguments: `name` and `species`. Set a property called `hunger` to `0` by default.
* **The Logic:** Add a method called `feed()` that increases the `hunger` by 10. Add a method called `play()` that decreases the `hunger` by 5.
* **Check Your Work:** Create a new pet object called `myPet` (give it your own name and species). Call `myPet.feed()`, then `myPet.play()`. Finally, log the `myPet` object to the console to see the final hunger level.

### 📦 Mission 2: The Adventure Gear Shop

Adventurers need equipment! You need to create a template to generate items for the shop.

* **The Mission:** Create a class called `Item`.
* **The Constructor:** Should take three arguments: `name`, `type`, and `price`.
* **The Logic:** Add a method called `applyDiscount()`. This method should take a number (`discountAmount`) as an argument and subtract that amount from the `price`.
* **Check Your Work:** Create an item called `sword` with a price of 50. Use the `applyDiscount` method to take 10 off the price. Log the `sword` object to the console to see the new price.

### 📦 Mission 3: The Superhero Training Room

Every hero needs to get stronger! You need a class to track their training sessions.

* **The Mission:** Create a class called `Hero`.
* **The Constructor:** Should take `name` and `powerLevel`.
* **The Logic:** Add a method called `train()`. This method should add 10 to the `powerLevel` and log a message to the console: "[name] is getting stronger!"
* **Check Your Work:** Create a hero object called `flash` with a power level of 50. Call the `train()` method twice. Log the `flash` object to the console to confirm the power level has increased.
