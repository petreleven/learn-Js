# C# Quiz – Creating Your Own Classes and Objects

### Question 1 – Pet Class 🐶

Create a class called **Pet** with these attributes:

* `name`
* `animalType`
* `age`

Then create an object called **myPet** and give it values.

Print the **name** of the pet.

---

### Question 2 – Car Class 🚗

Create a class called **Car** with these attributes:

* `brand`
* `model`
* `year`

Create an object called **myCar** and give it values.

Print the **brand** of the car.

---

### Question 3 – Game Character 🎮

Create a class called **GameCharacter** with:

* `name`
* `weapon`
* `level`

Create an object called **player1**.

Give the character values and print the **weapon**.

---

### Question 4 – Student Class 🎒

Create a class called **Student** with:

* `firstname`
* `school`
* `favoriteSubject`
* `age`

Create an object called **student1** and print their **favoriteSubject**.

---

### Question 5 – Superhero Class 🦸

Create a class called **Superhero** with:
