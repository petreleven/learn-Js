### 📦 Mission 1: The Galactic Treasure Hunter

* **The Mission:** Define a function called `calculate_gold`.
* **The Arguments:** Two parameters: `bag_one` and `bag_two`.
* **The Logic:** Return the sum of `bag_one` and `bag_two`.
* **Check Your Work:** Store the result in a variable named `total_gold` and use an f-string to print: `"Total treasure collected: [total_gold] coins!"`

### 📦 Mission 4: The Vending Machine Wizard

* **The Mission:** Define a function called `vending_machine`.
* **The Arguments:** One parameter: `money`.
* **The Logic:** Use `if`, `elif`, and `else` statements to return:
* `"Chocolate Bar"` if `money` is 10 or more.
* `"Bag of Chips"` if `money` is 5 or more (but less than 10).
* `"A piece of gum"` if `money` is less than 5.


* **Check Your Work:** Store the returned value in a variable called `my_snack` and print: `"I inserted my coins and received a: [my_snack]!"`

### 📦 Mission 6: The Minecraft Crafting Bench

* **The Mission:** Define a function called `craft_item`.
* **The Arguments:** One parameter: `raw_material` (a string).
* **The Logic:** Use `if`, `elif`, and `else` to return:
* `"Crafting Table"` if `raw_material` is `"Wood"`.
* `"Iron Sword"` if `raw_material` is `"Iron"`.
* `"Diamond Pickaxe"` if `raw_material` is `"Diamond"`.
* `"Stick"` for any other input.


* **Check Your Work:** Store the result in a variable called `my_item` and print: `"Success! You placed the material in the bench and got a: [my_item]!"`

### 📦 Mission 7: The Hacker’s Firewall Bypass

* **The Mission:** Define a function called `bypass_firewall`.
* **The Arguments:** One parameter: `security_level` (an integer).
* **The Logic:** Use `if`, `elif`, and `else` to return:
* `"Admin Access Granted"` if `security_level` is greater than 90.
* `"User Access Granted"` if `security_level` is between 50 and 90 (inclusive).
* `"Access Denied: Firewall Locked"` if `security_level` is less than 50.


* **Check Your Work:** Store the result in a variable called `status` and print: `"The terminal flashes: [status]"`
